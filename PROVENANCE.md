# Scientific input and software provenance

Six inert SQLite header files preserve their original public-domain notices. They are `src/hash.h`, `src/mutex.h`, and `src/pcache.h` from the official SQLite mirror at tags `version-3.46.0` and `version-3.47.0`. The tag commits are respectively `bebe2d8be8acfd02592c4972f4ba32c3b4e4a33f` and `f5fb820c0f4781337faf02ed871be68d13a83d94`. These immutable source identifiers describe external scientific inputs, not a project release manifest. Their raw bytes are included, so experiment reproduction needs no network.

The selected header pairs are unchanged between the tags. The resulting 25,582-byte fixture is a deliberate constructive test of repeated content, deletion and resurrection. It is not a representative workload or a measured database trace. SQLite code is not executed.

Synthetic events and operations are deterministically generated by the retained configuration and seeds. The `heldout` path is a stable filename, not a claim that revisions never consulted its contents. No statistical train/test guarantee is asserted.

The optional solver uses a locally available Z3 shared library through its public C API. Z3 internals are not modified; its MIT notice is retained. Experimental non-SMT paths use the Python standard library. Figure and typesetting resources belong to the paper package, not to this standalone repository.
